# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Modern modular component architecture in `/components`, semantic HTML5, Vanilla CSS design token system, and zero-defect layout verification.

## Users

Developers, designers, and AI coding agents building, assembling, and maintaining modular web interfaces and production-ready UI components.

## Product Purpose

A modular web application and UI component builder optimized for agentic workflows. It provides production-grade, highly aesthetic UI components and layout primitives with verified zero-defect layouts.

## Positioning

An agentic-first component builder combining deterministic quality gates, comp-first visual direction, and rigorous spatial audits to eliminate visual and structural debt.

## Operating Context

Modern desktop and mobile web environments. Component authoring, testing, and rendering verified against automated Impeccable design detector scans (`--scope layout`) and local preflight quality gates.

## Capabilities and Constraints

- Modular component system in `/components` covering foundational layout primitives, navigation, content blocks, data displays, feedback states, and forms.
- Mechanical layout gate: 0 findings on `.agent/skills/impeccable/scripts/impeccable detect --scope layout`.
- Vanilla CSS design tokens for spacing, typography, colors, elevations, and responsive breakpoints without framework lock-in.

## Evidence on Hand

Clean repository baseline with active fail-closed Git hooks and preflight scripts. Greenfield component architecture targeting zero layout anti-patterns.

## Product Principles

1. Zero Layout Debt: Every component must achieve and maintain zero layout anti-patterns under mechanical Impeccable audit.
2. Comp-First Direction: High-fidelity visual standards precede code assembly.
3. Proximity & Rhythm Over Containers: Spacing and semantic grouping lead structure; containers support rather than compensate for weak hierarchy.
4. Fail-Closed Verification: Automated gates prevent regressions from reaching commits.

## Accessibility & Inclusion

WCAG 2.1 AA compliance: semantic markup, proper heading structure, visible focus indicators, logical tab and focus sequence matching visual order, and minimum 44x44px touch targets.
